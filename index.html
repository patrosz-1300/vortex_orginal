Vortex HUD – Wiki

Client-side HUD and quality-of-life mod for Minecraft 1.21.11 (Fabric) with a menu of 117 modules.

📦 Installation

  1. Install Fabric Loader for Minecraft 1.21.11.
  2. Put Fabric API and the Vortex jar into your mods folder.
  3. Start the game. Requires Java 21.

🎮 How to use

  • Press Right Shift in game to open the menu (press it again or Esc to close).
  • Click a module card to turn it on or off.
  • Click Options on a card to change its color, chroma (rainbow) mode and other settings.
  • Drag any enabled HUD element with the mouse to move it. Reset positions puts everything back.
  • Use the tabs at the top and the mouse wheel (or the scroll bar) to browse modules.

⚙️ Configuration

Settings are saved automatically to config/vortex.json:

  • title – the name shown at the top of the menu (you can change it)
  • modules – per module: enabled, x, y (position), color, chroma, options

Delete the file to reset everything to defaults.

❓ FAQ

Does it work on servers?
Yes, it is client-side only. Nothing is installed on the server.
Are there cheats?
No combat automation. Some servers restrict things like fullbright or toggle sprint, so check your server rules.
Other Minecraft versions?
Only 1.21.11 at the moment.
Something is broken?
Report it with your logs/latest.log on the issue tracker.
